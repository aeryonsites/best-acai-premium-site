# Best Açaí Premium

Site do cardápio da Best Açaí Premium (Penápolis - SP): cardápio em carrossel, pedido pelo WhatsApp e horário de funcionamento.

- Site estático: `index.html` + pasta `img/`. Sem build, sem dependências.
- Para ver localmente, abra o `index.html` no navegador.
- Para publicar, use Vercel, Netlify ou GitHub Pages apontando para a raiz do repositório.

Site por Lucas Melo, criação de sites.
